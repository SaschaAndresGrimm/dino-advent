# CLAUDE.md

Oli & Fabios Dino-Advent (repo `dino-advent`): a German-language canvas runner, built as an advent calendar (24 daily levels from 1 Dec 2026) for two brothers, Oli (10) and Fabio (4). Both are heroes: Oli steers Rex, Fabio rides in front of him and is the "Brüll-Chef" (roar). Plain scripts in `js/` (no modules, no build), no dependencies at runtime. Read `docs/ARCHITECTURE.md` before larger changes; `docs/DEVELOPMENT.md` and `docs/MAINTENANCE.md` cover workflow and releases.

## Commands
```bash
npm run check     # node --check js/*.js sw.js
npm test          # Playwright, about 30 s, starts its own server on port 8790
npm run serve     # manual play on http://localhost:8765 (add ?day=12 to open day 12)
npm run screenshots  # regenerate docs/screenshots after visual changes
```
Run both check and test before every commit. Playwright needs `npx playwright install chromium` once.

## Rules of this project
- **Language:** all text the player sees is German, short and kid-friendly. Code, comments, docs and commits are English.
- **New source file:** add it to `index.html` (load order matters: top-level code runs in that order), to `FILES` in `sw.js` and, outside `js/`, to the copy step in `ci.yml`. No top-level function or `var` may share a name with a browser built-in; `tests/files.spec.js` checks both.
- **No build step, no external assets, no new runtime dependencies.** Art is vector drawing in canvas; sound is synthesised.
- **Release:** merging to `main` deploys via GitHub Actions (tests first). The deploy job stamps the service-worker cache name (`dino-advent-dev` in `sw.js`) with the commit; never hand-edit it and keep the literal `dino-advent-dev` so the stamping works. New shipped files must be added to the copy step in `.github/workflows/ci.yml`.
- **Commits:** end the message with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commit and push only when the user asks. Remote: `origin` (GitHub, branch `main`).
- **Save compatibility:** never rename or remove fields of the save (`olisDinoRettung.v1`). Add new ones with defaults in `buildSave` (`js/core.js`) and add the field to `SAVE_TYPES`.

## Conventions
- Logical size 960×540; ground at `GROUND = 440`. Use `G.p.wx` for the world x of the player; screen x = world x − `cam`.
- Level generation is seeded and deterministic per level. Do not use `Math.random()` inside `buildLevel` (use `R()`); effects at runtime may use `Math.random()`.
- A new obstacle type needs three places: the `switch (o.type)` in `updatePlay`, `drawObstacle`, and the interactions (`roar`, fireball loop, `dashBreak`). Then add a pattern in `buildLevel`'s `P`, put it in the `WORLDS[...].patterns` lists, classify it in `HARD`/`COMBO` if needed, and teach the bot.
- Anything with state that a respawn can break (crumbling platforms, fallen meteors) must be reset in `retry()` and `pitFall()`.
- Hints must come early: `firstTip` uses `x - 1200`; tutorial coach points are 150 to 300 px before the obstacle. Hints and coach must never mention a skill the player has not learned yet (`SKILL_DAYS`: dash 4, duck 7, swim 10, stomp 13, glide 16, fire 19).
- Boss fights: Rex stands still (FLITZ lunges him forward and back). Collectibles must come to him (they drift and hearts are magnetic). The boss must walk back to `home` between phases. Enemy waves need wide spacing (200+ px) so a jump fits between them.
- Sound: every new SFX goes in the `SFX` table (synthesised). Screens decide the music in `musicKey()`/`musicOpts()`/`musicLevel()`; the finale uses `SONGS.ending`. Overlays never cut the song: use `vol` in `musicOpts()` (the song fades, 0 stops it after the fade).
- Sound checks: after any sound change run `AUDIO_REPORT=1 npx playwright test tests/audio.spec.js` for peak/loudness per song, effect and ambience bed (offline render of the real synthesis). New songs go in `ALL_SONGS`, new effects in `SFX_LIST` (`tests/audioRender.js`).
- Boss music: every boss kind needs a `SONGS['boss_' + kind]` entry (same `root` as its world, `epic: true`, own `seed`); without one the world song just keeps playing. Notes with `bus === 'music'` go through `musicIn`; the fanfare and riser use `bus = 'fanfare'` so the fade does not mute them.
- Do not draw over the HUD area at the top centre (eggs, progress bar, boss bar). Hint boxes go at the bottom (max 3 lines, they must stay below the ground line); boss banners sit at y=134 (compact, 2 s), boss toasts at y=78 (one at a time; minor ones are filtered by BOSS_QUIET). Keep Chili at 145 px behind Rex so the two silhouettes do not merge.

- **Kid-friendliness helpers:** `chiliSay(text, force)` shows a rate-limited speech bubble from Chili; `cheer()` celebrates the first successful use of a taught move; hearts are `MAX_HEARTS` (4) in story levels and 3 in endless/daily (`G.maxH`; never hard-code a heart count); the second retry at the same checkpoint and the start of every boss fight set `G.shield` (absorbs one hit, `hurt()` checks it). `save.newGifts` (`"key:index"`) drives the NEU badges on the map and in the shop and is cleared when the shop closes.
- **Bestenliste:** local per-device top 10 per theme in `save.board[wi]` (`{n, s, t}`), `boardAdd`/`boardQualifies`, scene `'board'`. Names go through `cleanNick` (profanity, leetspeak, e-mail/URL/number checks); add words to `BAD_WORDS`. Parent mode can clear the board. No network: an online backend would need a new design decision (privacy of children's names).

- **Story:** the Krallenkönig stole the dino family's golden egg; the bosses of days 6, 12 and 18 each hold a piece of his map. `DAY_STORY[day]` is a short Götti dialog played once before a level (via `launchLevel`, tracked in `save.storySeen`), `DAY_AFTER` plays on the map after the first boss win (`save.afterNew`), `TEASERS` replace the results-screen line on days 5, 11, 17 and 23. Use `{oli}`, `{fabio}` (both asked in the intro, defaults Oli/Fabio; `save.fabioName`), `{rex}` and `{baby}` in texts, never a hard-coded name. Story lines speak to both boys ("ihr zwei"); gameplay hints stay singular (they address whoever holds the tablet). `who: 'fabio'` is the boy Fabio (portrait = his face); the dino family is only Mamasaurus and Papasaurus. Both boys are drawn by `drawOli` (`o.kid: 'fabio'` switches the outfit); Fabio is drawn through the `front` hook so Oli's rein arm wraps round him. Keep every new story line German, short and Swiss-spelled (ss, no ß).

- **Settings and daily run:** `save.volMusic`/`save.volSfx` (0-5, 4 = normal) scale `tone()`/`noise()` through `bus` (`musicTick` sets `bus = 'music'`); `save.calm` disables screen shake and the red hit flash. Tages-Lauf = an endless run seeded by `dayKey()` (`startDaily`), world chosen by `dailyWorld()`, +20 amber and a streak once per day, daily board is `save.board[8]` and resets each day. The iPad install hint shows once on the map (`save.installHint`).

- **Collection milestones:** all 72 medals (`medalTotal()`) set `save.master`, grant and equip the shop items with `gift: 25` (Dino-Meister skin, Meister-Krone) and start a map celebration (`mapFW`, dialog). A world's doors get a gold frame when `worldMedalsDone(wi)`. The 4th treasure triggers `chestParty()`; a full chest can be tapped to replay it. `gift: 25` in `SKINS`/`HATS` means "earned with 72 medals", never granted by a door.

- **Shop tabs (`SHOP_TABS`):** Rex, Feuer, Hüte, Jacken, Chili, Götti. Each tab has an owned key and a list of equip slots: hats and jackets have one slot per boy (`hat`/`fabioHat`, `jacket`/`fabioJacket`, "Oli anziehen" / "Fabio anziehen"), Chili one (`chili`, drawn by `drawChiliAcc`), vouchers none. `JACKETS` index 0/1 are the boys' free default jackets. `WISHES` are real-life vouchers from Götti (shared, bought once, shown by `drawVoucher`); change their texts or prices there. Door gifts show "Geschenk", never "Gekauft". A hat door gift equips on both boys.
- **Shop, Steckbrief, Schatzkarte:** the shop scene lives in `shopScene()`/`shopCounter()` and the 100 px item cards in `drawShop` (status pills: owned, Tür N, price). The Dino-Buch detail view reads `FACTS[i].text` (`headline|Wusstest-du detail`, the `|` is required) and `STECK[i]`: `l`/`e` era text, `tl: [from, to]` span in million years ago (drawn on the Trias/Jura/Kreide/Heute strip), `d`/`dk` diet, `m` metres for the to-scale ruler (`ml` label, `fb: 1` = bar-and-children fallback, `m: 0` + `cmp` = custom comparison), `nm`/`nl` the name-meaning chip. Add both entries whenever a card is added; the real animal in the ruler and the habitat scene use `cardBox` (measured from the card sprite). The `Grössen` button opens the to-scale lineup (`bookMode = 'lineup'`, drag-scroll via `lineDown/Move/Up`). The level-complete card is a button into the book (`openBookCard`). `drawTMap` shows the three torn map pieces (days 6, 12, 18 via `tmHave`); after a boss follow-up dialog `tmapNew` triggers the reveal animation.

- **Göttis Schätze (hidden treasures):** days 3, 9, 15, 21 each hide one treasure behind a move the boys already know, built in the `i === tAt` branch of `buildLevel` (`L.secret` + `L.treasure`, the treasure stays `shown: false` until `openSecret`): guitar in the sleeping Brüll-Baum (roar within 640 px ahead), bike in a cracked rock (`sec: true` obstacle, dash/fire/stomp opens it via the `o.dead` check), rod in the ice hole (stomp landing within 130 px), Kiwi under the ash heap (fire; a dedicated pepper with `sec: true` is placed before it and given back by `resetSecretPepper` on respawn). Cues are audio first (`secretCue`: a sound that grows louder, Chili speaks once, a faint glint) because Fabio cannot read. Hint ladder: `save.tTries[k]` counts finished runs without the treasure; 1 miss adds a tip text (`TREASURES[k].tip`), 2 misses a brighter glint and halo. The results line is `TREASURES[k].hint`. Never put the secret on the main path and never make a miss cost hearts.

- **Followers:** Chili (145 px behind Rex), the baby (`FOL.baby`) and Kiwi (`FOL.kiwi`) replay Rex's path: `trailPush` records his height by world x each frame, `followY(x)` reads it (never below `GROUND`, plus a safety hop over pits), so they hop where Rex hopped without per-obstacle rules. Anything that teleports the player or respawns him must call `resetTrail()`. Keep follower offsets small enough to stay on screen (Rex is at screen x 270). The touch buttons (`duckPos()`, `dashPos()`, BRÜLL) live in the soil band below the ground line so they never hide the followers; the trail also remembers the platform Rex stood on, so followers ride a crumbled step down.

- **Underwater roar (Blasen-Brüll):** in swim levels `roar()` uses `SFX.roarWater` and `swimRoar()` (bubbles, pale-blue ring, a wave front via `p.bubT`) and reacts to more than land: jellies drift out of Rex's lane (`o.ty`), urchins get bubble-wrapped (`o.scared`, no hitbox, 3 amber), amber within 360 px is pulled to Rex (`a.pull`). Never make any of this required to pass a level.

- **Game feel:** the first ground jump is variable: `jump()` sets `p.jh`, and `jumpRelease()` (pointer/key release) cuts `vy` to `-HOP_V`, so a short tap is still a real hop and only releases within ~0.11 s change anything. Never cut bounce pads, double jumps or swimming. `G.jbuf` (`JUMP_BUF`) remembers a jump pressed just before landing when both jumps are used up. `nearMiss()` pays 2 amber (cap `NEAR_CAP` per level, `G.nearN`) for clearing a non-ceiling hazard within `NEAR_PX`; it is off in boss fights, while dashing or invulnerable. Boss entrance: letterbox bars (phase 0 only), `G.zoom` pulse and `G.freeze` on arrival, and the banner stamp (`G.banner.hit` plays `SFX.stamp`). `drawFarForeground` (fast soft shapes at the top edge, off in `LOWFX`) and `colorGrade` (`GRADE`, indexed by theme `G.wi`, not art set) are drawn last, below the vignette. Check for `undefined` before comparing (`p.dashT` is undefined until the first dash, so use `!(p.dashT > 0)`).

- **Look (art pass):** `glow()` is a cached additive sprite (amber, eggs, Rex halo `REX_LIGHT`; no-op in `LOWFX`). `desatBackdrop` (`DESAT`) drains the backdrop right after `drawBackground` so Rex, enemies and pickups are the most saturated things on screen. `outlined(..., rim)` adds a thin light edge on the upper left (`oRex` warm, `oRaptor`/`oPtero`/`oCompy` red-orange = hazard). Boss arena: `G.arena` (0..1) eases in while `G.bossStarted` and drives `arenaBack`/`arenaFloor` (darker backdrop, stone slab floor). Boss pose in `drawPlay`: idle breathing plus a crouch-and-lean-back (`ant`) before each attack; the king never rotates (axis-aligned outline cache). Payoffs: amber pickups push `G.flyAmb` (arc into the HUD counter, `G.amberPop`), eggs and treasures set `G.slowT`/`G.zoom` and play `SFX.rise`, boss arrival plays `SFX.bossSting`. The action buttons (`actBtn`) are carved wood with amber studs around a gem-coloured centre and the hint bar is a parchment `scrollBox`; keep their hit areas unchanged.

- **Boss telegraphs:** every attack is announced first with `bossTele(b, dur)` (sets `b.tele`: red glow and '!' badge on the boss, wind-up pose through `ant`, `SFX.warn`). Taunt fires it 0.5 s before the attack (not for `lane`, whose red stripes are the warning, `leap`, whose crouch is, nor `volley`, which winds up before every shot), volleys wind up before each shot and show a lane marker (`v.warnY`), the boss's own charge after a summon goes through the `windup` state, and `quake` (crab phase 3: stomp, then a ground shock wave to jump) winds up before every slam. A new attack must call `bossTele` first; `tests/game.spec.js` ('boss telegraphs') fails on any unannounced projectile, wave or charge.

- **Advent candles (`js/candles.js`):** `CANDLE_DAYS = [1, 6, 13, 20]` (the 1st Advent, 29 Nov 2026, is before the calendar opens, so candle 1 is lit on day 1). `candlesDue()` counts the days reached via `adventDay()`; `save.candles` (0-4) is what burns. `go('map')` calls `queueCandle()`: if a candle is due it waits for any running dialog (wraps `dialog.done`), then `startCandle()` opens scene `'candles'` (Rex walks in, tap or a 7 s timer sends a Zündfunke, `candleIgnite()` saves at once, pays `CANDLE_AMBER` and plays Götti's lines, `Weiter` goes back to the map, which starts the next due candle; the wait phase also chimes softly because Fabio cannot read). Tapping the small wreath on the map replays the last candle (`startCandle(true)`, no amber, nothing saved). The spark is its own effect (`SFX.spark`/`SFX.candle`), never the fireball skill (learned on day 19). The flame uses the equipped fire colour. `drawWreath(cx, cy, s, lit, pulse)` (leaf layers cached per scale in `wreathCache`) is also drawn small on the map and in the finale. `tests/helpers.js` BASE_SAVE sets `candles: 4` so other tests see no ceremony; candle tests override it.

## Testing pitfalls
- `tests/levels.spec.js` has a bot (`PLAY`) that must be able to finish every level. New obstacles usually need a rule there. If it fails with `done:false, steps:60000` the bot is stuck: step it in small chunks and print position, nearby pits/platforms/obstacles.
- Tests run with service workers blocked and a fake clock only where they say so (`calendar.spec.js`).
- Use `game.open(saveOverrides)` from `tests/helpers.js`; set `G.startT = 0` and clear `G.coach` to skip intro and tutorial freezes.
- Screenshots for visual checks: `page.screenshot` in a temporary spec; set `G.freeze = 9` to hold a frame still. Delete temporary specs afterwards.
